## 📖 About This Project

This is a fully animated interactive quiz website
converted from a Python project into a beautiful
web application with real-time data collection!

> Originally built as a Python terminal quiz,
> now transformed into a gorgeous web experience!

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🧠 **3 Quiz Categories** | Psychology, AI Affairs, Math |
| 📝 **5 Questions Each** | Carefully selected questions |
| ✅ **Instant Feedback** | See right/wrong immediately |
| 📊 **Score Tracking** | Your score shown live |
| 🔍 **Answer Review** | Review all answers after quiz |
| ⭐ **Rating System** | Rate and review the quiz |
| 📱 **Mobile Friendly** | Works on all devices |
| 🌙 **Dark Theme** | Easy on the eyes |
| 📈 **Data Collection** | Results saved automatically |

## 📊 Data Collected

When someone plays the quiz:
✅ Player name
✅ Quiz they played
✅ Score they got
✅ Percentage
✅ Date and time
✅ Which answers they chose
✅ Star rating (if reviewed)
✅ Their feedback
✅ Difficulty opinion
